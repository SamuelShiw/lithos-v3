# 💎 LITHOS V3 — Sistema de Control Minero

**LITHOS V3** es una solución SaaS diseñada para la gestión operativa, control de costos y seguridad en minería subterránea. Desarrollado en Python, permite la toma de decisiones basada en datos en tiempo real.

## 🚀 Características Principales

- **Tablero de Control (Dashboard):** KPIs en tiempo real, cotización de minerales (Oro/Plata) y alertas de paradas.
- **Registro Operativo:** Parte diario digital con firma electrónica y checklist de seguridad.
- **Control de Costos:** Cálculo automático de costos por guardia (Soles/Dólares).
- **Reportabilidad:** Exportación de reportes ejecutivos en PDF y Excel.

## 🛠️ Tecnologías

- **Frontend:** Streamlit (Python)
- **Backend/DB:** Supabase (PostgreSQL)
- **Finanzas:** Yahoo Finance API (yfinance)
- **Visualización:** Pandas & Altair
